# ドローン企業サイト UX設計ドキュメント

---

## ① コンバージョン（目的・概要）

### 目的（CV）

- 法人・個人事業主からの問い合わせ獲得（導入・協業・見積依頼）
- 展示会や技術発表への誘導（イベント参加）
- 採用エントリー（エンジニア・運用オペレーターなど）

### サイトのゴール

企業・自治体・農業事業者などに向けて、「ドローン×データ可視化で課題を解決できる企業」として信頼を構築し、問い合わせ・資料請求・採用応募などの行動につなげる。

## ② ペルソナ＆ユーザージャーニー

### ペルソナ① 建設会社技術部課長（BtoB）

| 項目 | 内容 |
|------|------|
| **年齢 / 性別** | 42歳 / 男性 |
| **職業 / 役職** | 建設会社 技術部 課長 |
| **課題** | 現場効率化・安全性向上・老朽化施設の点検コスト |
| **目的 / 動機** | ドローン導入で現場課題を解決し、上司に提案する |
| **情報収集経路** | Google検索・業界誌・展示会 |

#### 行動パターン

1. 検索で技術・導入事例を確認
2. 技術ページで信頼性確認
3. PDF資料ダウンロード or 問い合わせ
4. 上司に提案

#### 重視ポイント

導入実績・精度・安全性・運用サポート

#### 離脱理由

導入コストが不明、信頼性が見えない

#### 必要情報 / CTA

SERVICE・TECHNOLOGY・CASE・資料ダウンロード・CONTACT

#### 推奨導線

**TOP → SERVICE → TECHNOLOGY → CASE → CONTACT / 資料ダウンロード**

## ③ ブランドコンセプト

### メインコンセプト

**「空から社会を変えるテクノロジーを。」**

ドローンとAI・クラウドを組み合わせ、社会インフラ・農業・防災などの現場課題を"見える化"することで、未来の社会インフラを支える。

### ブランドトーン

技術に裏づけられた信頼感 × スマートで先進的な印象を演出

## ⑥ トップページ セクション構成

### セクション① ヘッダー（HEADER）

**要素**：ロゴ + グローバルナビゲーション

**ナビゲーション項目**：HOME / SERVICE / TECHNOLOGY / CASE / ABOUT / RECRUIT / CONTACT

**スタイル**：ネイビーブルー背景、ホワイトテキスト、粘性ナビゲーション対応

---

### セクション② メインビジュアル（MAIN VISUAL / ヒーロー）

**キャッチコピー**：「ELEVATE THE FUTURE」

**背景**：ドローン×データ可視化の動画または高品質背景映像

**CTA ボタン**：「サービスを詳しく見る」「お問い合わせ」

**デザイン効果**：アニメーション、グリッドエフェクト、グラデーションオーバーレイ

---

### セクション③ イベントバナー

**テキスト**：「Japan Drone 2025 出展決定」

**CTA ボタン**：「詳しく見る」

**配置**：セクション間のバナー形式（アテンション喚起）

---

### セクション④ SERVICE（事業内容紹介）

**表示形式**：アイコン + 写真 + 説明テキスト

**扱うサービス**：
- 運用支援
- 点検測量
- 農業支援
- 災害対応

**レイアウト**：グリッド配置（3〜4列）、ホバーエフェクト付き

---

### セクション⑤ TECHNOLOGY（技術紹介）

**背景**：暗め（グラデーション、ダークネイビー）

**扱う技術**：
- AI解析
- クラウドシステム
- フライト制御

**ビジュアル**：テック感あるアイコン、プロセスフロー図

**テキスト**：各技術の説明と競争優位性

---

### セクション⑥ CASE（導入事例）

**表示形式**：カードデザイン（写真 + 実績 + 詳細リンク）

**業種別ケース**：自治体 / 建設 / 農業 / 防災

**要素**：
- 事例画像
- クライアント名 / 業種
- 課題・解決策・成果
- 「事例を詳しく見る」リンク

**レイアウト**：横スクロール または グリッド配置

---

### セクション⑦ ABOUT（企業情報）

**扱う内容**：理念 / 沿革 / 代表メッセージ

**レイアウト**：
- 理念セクション：テキスト中心
- 沿革：タイムラインまたは表形式
- 代表メッセージ：顔写真 + インタビュー形式

**トーン**：社会貢献性を強調

---

### セクション⑧ RECRUIT（採用情報）

**要素**：
- 社員インタビュー（顔写真 + Q&A）
- 募集職種一覧
- 応募導線

**デザイン**：青 × ホワイト、未来的で活力あるビジュアル

**CTA**：「応募する」「詳細を見る」

---

### セクション⑨ NEWS（お知らせ）

**表示形式**：ニュース一覧（日付 + タイトル + カテゴリ + リンク）

**カテゴリ**：展示会 / 技術発表 / 採用情報

**レイアウト**：カード形式 または リスト形式

---

### セクション⑩ CONTACT（問い合わせ）

**表示形式**：シンプルなフォーム

**フォーム項目**：
- 企業名 / 個人名 *
- メールアドレス *
- 電話番号
- お問い合わせ内容 *
- お問い合わせ区分（導入相談 / 採用 / その他）

**デザイン**：信頼感あるスタイル、ホワイトスペース活用

**セキュリティ表示**：プライバシーポリシーへのリンク

---

### セクション⑪ フッター（FOOTER）

**要素**：
- ロゴ
- グローバルナビゲーション再掲（SERVICE / TECHNOLOGY / CASE / ABOUT / RECRUIT / CONTACT / NEWS）
- SNS リンク（LinkedIn / Twitter / YouTube など）
- コピーライト表記（© 20XX Drone Company. All rights reserved.）
- プライバシーポリシー / 利用規約リンク

**バックカラー**：ネイビーブルー

## ⑦ レスポンシブ対応ガイドライン

### ブレークポイント

- **デスクトップ**：1200px以上
- **タブレット**：768px 〜 1199px
- **モバイル**：767px以下

### モバイル対応ポイント

- ハンバーガーメニュー（ナビゲーション折りたたみ）
- セクション幅の調整（フルスクリーン対応）
- カード・グリッドの縦積み
- フォント サイズの最適化
- タッチターゲットサイズ（最小 48px）

---

## ⑧ SEO・アクセシビリティ対策

### SEO 施策

- メタデータ最適化（タイトル・メタディスクリプション）
- 構造化データ（Schema.org）対応
- ALT テキスト設定
- 高速化（画像圧縮・キャッシング）

### アクセシビリティ対策

- WCAG 2.1 AA レベル準拠
- コントラスト比 4.5:1 以上
- キーボード操作対応
- スクリーンリーダー対応
